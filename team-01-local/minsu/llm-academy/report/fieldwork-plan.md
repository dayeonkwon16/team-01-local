## 기획 세 칸

| 칸 | 내용 |
|---|---|
| 1. 기획 목적 | 우리 팀 서비스(창업, 소상공인 업종 추천)를 위해, 오늘 못 채운 빈칸을 사람들의 말로 채울 계획을 세운다 |
| 2. 최우선 판단 기준 | 오늘 리포트에서 '말할 수 없는 것'으로 남은 것을 확인할 수 있는 소스를 먼저 |
| 3. 대상 / 제외 | 대상: 서면, 서면젊음의거리를 찾은 20~30대 여행자 / 제외: 광고·체험단 글, 같은 글, 로그인해야 보이는 글 |

## 수집 계획

판단 기준 2에 따라 빈칸을 더 많이 확인할 수 있는 소스를 위에 두었습니다. 카카오맵은 오늘 모은 소스라서 맨 아래에 두었습니다.

| 소스 | 수집 항목 | 담당 | 분량 | 출처 한 줄 양식 | 오늘 결과에서 확인할 것 |
|---|---|---|---|---|---|
| 1. 네이버 블로그 여행 후기 (검색어 후보: 서면 여행 코스, 서면젊음의거리 밤, 서면 1박 2일) | 게시일, 방문 요일·시간대(글에 적힌 경우만), 들른 가게의 업종(가게 이름 대신 업종), 붐빔·웨이팅 문장 원문, 만족·불만 문장 원문, 글에 적힌 나이·여행 여부 | | 글 6건 (한 사람 약 1시간) | `네이버 블로그 · 서면젊음의거리 · YYYY-MM-DD(게시일) · <글 링크> · 모은 날 YYYY-MM-DD` | A, B, D, F |
| 2. 유튜브 서면 여행 브이로그 (검색어 후보: 서면 브이로그, 부산 서면 밤, Seomyeon vlog) | 올린 날, 영상에서 말한 방문 요일·시간대, 해당 구간 [분:초], 보행자 수 대략(적음/보통/많음), 들른 업종, 버스킹 장면 여부, 만족·불만 말(자막·말 원문) | | 영상 3개, 서면 구간만 (한 사람 약 1시간) | `YouTube · 서면 · YYYY-MM-DD(올린 날) · <영상 링크> · 모은 날 YYYY-MM-DD` | A, B, C, F |
| 3. 구글맵 외국어 리뷰 (서면젊음의거리 말고, 서면 안 다른 장소. 예: 전포카페거리) | 별점, 리뷰 원문(자동 번역 말고 '원본 보기'), 작성일(화면 표시 그대로), 리뷰에 적힌 방문 시간대, 버스킹·붐빔 문장 | | 글 있는 리뷰 최신순 10건 (한 사람 약 30분) | `구글 지도 · 전포카페거리 · 작성일(화면 표시 그대로) · <장소 링크> · 모은 날 YYYY-MM-DD` | A, C, D, E |
| 4. 트립어드바이저 서면 영어 리뷰 | 별점, 리뷰 원문, 작성일, 방문 시기(사이트에 표시된 경우), 동행 유형(사이트에 표시된 경우), 버스킹·붐빔 문장 | | 글 5건 (한 사람 약 30분) | `트립어드바이저 · 서면젊음의거리 · YYYY-MM(작성일) · <리뷰 링크> · 모은 날 YYYY-MM-DD` | C, D, E [확인 필요: 로그인 없이 리뷰 전체가 보이는지] |
| 5. (나중에) 카카오맵 서면젊음의거리 | 오늘 잘린 4건(연번 1, 2, 3, 8)의 전체 글. '더보기'를 누른 뒤 다시 복사 | | 4건 (약 10분) | `카카오맵 · 서면젊음의거리 · YYYY.MM.DD.(등록일) · https://place.map.kakao.com/335140347#review · 모은 날 YYYY-MM-DD` | 잘린 글 때문에 놓친 태그가 있는지 (C의 1번 "거리연주" 글 포함) |

- 분량 합계: 소스 1~4에서 6 + 3 + 10 + 5 = **24건** (팀 목표 20건 이상). 소스 5는 합계에 넣지 않음.
- 담당 칸은 팀이 정합니다.

## 대상과 제외 기준

| 구분 | 기준 | 이유 |
|---|---|---|
| 대상: 20~30대 여행자 | 글·영상에 "여행", "놀러 옴", 숙소, 다른 지역에서 옴 같은 말이 있으면 여행자로 봄. 나이는 글에 적힌 경우에만 적음 | 프로필 사진·닉네임으로 나이를 짐작하면 지어내는 것이 됨 |
| 제외: 광고·체험단 글 | "체험단", "협찬", "원고료", "제공받아" 같은 표시가 있는 글 | 대가를 받은 글이라 만족·붐빔을 부풀릴 수 있음 |
| 제외: 같은 글 | 같은 사람이 여러 곳에 올린 같은 글, 다른 글을 그대로 옮긴 글은 1건만 셈 | 같은 말이 여러 번 세어지면 건수가 부풀려짐 |
| 제외: 로그인해야 보이는 글 | 로그인 없이 열리지 않는 카페 글, 비공개 계정 글 | 링크를 다른 사람이 열 수 없어 출처를 확인할 수 없음 |
| 이번에 안 넣은 소스 | source-map의 지역 커뮤니티·로드뷰 | 가게 주인·빈 점포 이야기라 이번 대상(여행자)과 다름 |

## 남기는 법

| 구분 | 어디에 | 무엇을 |
|---|---|---|
| 원본 | 내 PC 비공개 폴더 `raw/` (예: `raw/2026-11-18-blog-서면여행-01.txt`) | 복사한 글·자막을 통째로. 파일 맨 위에 출처 한 줄 |
| 정리본 | `inputs/` (CSV) | 수집 항목만 뽑은 표. 닉네임·프로필·얼굴은 넣지 않음 |
| 공개·발표 | `report/`, 발표 자료 | 건수, 짧은 인용(한 줄), 원문 링크만. 원문 통째로 붙이지 않음 |

- `raw/`는 팀 공유(`/올리기`)에 올리지 않습니다.
- 공개 자료에 넣는 인용도 글쓴이를 알아볼 수 있는 부분(닉네임, 가게 주인 이름 등)은 빼고 옮깁니다.

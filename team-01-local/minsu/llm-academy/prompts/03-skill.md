# 03 · 세계관을 브랜드 스킬 파일로 (7일차 3교시)

먼저 `/clear`. 노란 칸 둘을 바꿉니다. `[스킬 이름]`은 영문 소문자와 붙임표(-)만 쓰고, 오전에는 끝에 내 이름을 붙입니다(예: `dongnae-day-inae`). 두 곳에 나오니 똑같이 바꿉니다.

```text
내 이름 폴더의 brand/persona.md와 brand/worldview.md를 읽고, Claude가 읽는 브랜드 스킬 파일 .claude/skills/[스킬 이름]/SKILL.md를 만들어 줘.
[1. 나의 기획 목적] 누가 어떤 글을 부탁해도 [브랜드 이름]의 말투와 사실로 쓰게 한다
[2. 최우선 판단 기준(우선순위)] 사실 규칙이 말투보다 먼저다. 확인되지 않은 것을 확인된 것처럼 쓰지 않는다
[3. 타깃 대상 및 제외할 노이즈] 대상: 게시물·안내문·카피·대본을 쓸 때 / 제외: 표 만들기, 숫자 세기처럼 글쓰기가 아닌 일
1. 맨 위는 이 모양 그대로:
---
name: [스킬 이름]
description: [브랜드 이름]의 목소리로 글(게시물·안내문·카피·대본)을 쓸 때 쓴다.
---
2. 그 아래 차례: 톤(말투 규칙) · 핵심 메시지 셋 · 금칙어 · 사실로만 쓸 것(값과 출처, 값이 엇갈리는 것은 둘 다) · 예시 문장(좋은 예 둘, 나쁜 예 둘) · 글을 다 쓴 뒤 확인할 것
3. 금칙어는 후보 다섯까지만 쓰고, 후보마다 까닭(어떤 원문이나 규칙 때문인지)을 붙이고 [사람이 정함]이라고 표시해.
4. persona.md와 worldview.md에서 [제안]으로 남은 말투와 설정은 그대로 [제안]으로 옮기고, 네가 새로 정하지 마.
5. 80줄을 넘기지 마. 긴 근거는 worldview.md의 어느 칸을 보라고만 적어.
```

"저장할까요?"라고 물으면 `응, 저장해.`

**허락 창:** `.claude` 폴더는 Claude의 설정이 들어 있는 곳이라, 쓰기 전에 따로 묻습니다. 아래 줄을 고릅니다.

```text
Yes, and allow Claude to edit files in this project's .claude folder for this session
```

이렇게 되면 성공: VS Code 탐색기에 `.claude/skills/스킬이름/SKILL.md`가 보이고, 맨 위 `---` 두 줄 사이에 `name`과 `description`이 있습니다.

## 사람이 정해 넣는 한 줄

Claude가 `[제안]`이나 `[사람이 정함]`으로 남긴 말투와 금칙어는 우리가 정해서 보냅니다.

```text
SKILL.md에 반영해 줘. 말투: [우리가 정한 말투 한 줄]. 금칙어: [남길 것 셋]. 나머지 후보는 지워.
```

## 막히면

- "권한이 없어 저장하지 못했어요": `SKILL.md도 저장해.`를 보내고 위 허락 줄을 고릅니다.
- 새 대화에서 `Skill` 줄이 안 보이면: 부탁 앞에 `/스킬이름`을 붙여 보냅니다.
- 예시 결과: `../examples/dongnae-skill.md`

## 4. 같은 사실을 두 번 세게 될 곳

| 어디서 | 무엇이 겹치나 | 어떻게 피하나 |
|---|---|---|
| 데이터 확보 ↔ AI 구현 | 둘 다 기관 통계·API를 보게 됨(T10, T11, T12, T14). API가 있는 줄이 두 기준에서 함께 높아짐 | 데이터 확보 = 몇 건·몇 종류(양), AI 구현 = 다시 받을 수 있는 형태인지(모양)만 봄 |
| T10 ↔ T11 | T11 근거 원문에 전포동 폐업률 2.14%(63 / 2941)가 함께 들어 있음. 이 숫자는 T10의 사실 | 전포동 숫자는 T10에서만 셈 |
| T12 ↔ T14 ↔ T15 | 같은 생활인구·카드 API. T12 원문에 전포1동 방문인구 5973(T14의 사실)이 들어 있음 | 전포1동 숫자는 T14에서만 셈 |
| T01 ↔ T02 ↔ T03 | 같은 통계청 첨부 PDF와 국제신문 기사 1건을 세 줄이 근거로 씀 | 데이터 확보에서 같은 PDF·기사를 줄마다 새로 세지 않음 |
| T05 ↔ T18 | 서면/전포 임대료 50.1천원/㎡(R-ONE 정리 xlsx)가 두 줄에 다 있음 | 임대료 숫자는 한 줄에서만 셈 |
| T19 ↔ T20 ↔ T21 ↔ T23 ↔ T25 ↔ T29 | 같은 구글 리뷰 요약 100건과 다연 리뷰 태그 파일이 여러 줄의 데이터 가용성에 들어 있음 | 데이터 확보 점수는 T19(거리 전체)에서 크게 주고, 나머지 줄은 그 줄만의 건수(13건, 17건 등)만 봄 |
| T01 ↔ T08 | 둘 다 '전포역 상권'이지만 정의가 다름(통계청 vs 부산시 변화지표) | 같은 상권으로 보고 합치지 않음. 숫자를 섞지 않음 |
| T26 ↔ T27 ↔ T28 | 같은 서면젊음의거리 리뷰·영상 자막에서 나온 줄 | 같은 리뷰·자막 줄을 두 줄에서 세지 않음 |

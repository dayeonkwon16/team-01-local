# 서면 대시보드, 누구를 위해 만들까?

- 작성: 황민수 · 2026-11-17
- 팀: 붐빔 (회의 자료)
- 확인한 날짜: 2026-11-17

부산 소상공인 매출 대시보드를 서면에서 먼저 시험해 보려고 합니다. 만들기 전에 방향 하나를 정해야 해서 후보 3개를 한 장에 비교했습니다.

## 1. 먼저 정할 질문 하나

> **이 대시보드를 누가 보고, 보고 나서 무엇을 결정하나요?**

이게 정해지면 모을 자료, 그릴 차트, 기획서 첫 줄이 같이 정해집니다.

## 2. 후보 A · B · C

| | A ⭐ 연습용 추천 | B | C |
|---|---|---|---|
| 보는 사람 | 서면에 가게를 열려는 **예비 사장님** | 서면에서 이미 장사하는 **기존 사장님** | **부산진구청 · 서면 상인회** |
| 결정하는 것 | 어떤 업종으로, 어느 동에 열까 | 축제·행사 때 영업시간·재고·인력을 늘릴까 | 어느 동·업종을 먼저 지원할까 |
| 보여 줄 것 | 동별·업종별 가게 수, 경쟁 정도 | 빛축제 기간 손님·매출 변화 | 업종별 늘고 줄어드는 흐름, 폐업 |
| 지금 있는 자료 | ✅ 가게 수 | ✅ 축제 일정 | ✅ 현재 가게 수 |
| 아직 없는 자료 | ❌ 손님·매출 | ❌ 기간별 매출 | ❌ 과거 비교 자료 |
| 난이도 | 쉬움 | 어려움 | 보통 |

| 기준 | A 예비 사장님 | B 기존 사장님 | C 구청·상인회 |
|---|---|---|---|
| 바로 시작할 수 있나 | 예, 가게 수 자료로 | 아니요, 매출 자료 필요 | 일부, 과거 자료 필요 |
| "매출 대시보드"와 맞나 | 2단계에서 매출을 붙여야 맞음 | 가장 잘 맞음 | 보통 |
| 리테일 기업 포트폴리오 | 상권 분석, 출점 판단 | 프로모션 효과 분석 | 공공 정책 쪽 |
| 다른 지역으로 넓히기 | 쉬움, 동 이름만 바꾸면 됨 | 축제가 있는 곳만 | 쉬움 |

- B는 지윤님 노트(`team-01-local/jiyoon/research/2026-11-12-seomyeon-1st-street.md`)의 가설 "축제 인파가 매장 매출로 이어지나"와 바로 연결됩니다.
- **추천: A로 첫 화면을 만들고, 손님·매출 자료를 찾으면 B로 넓히기.** A의 "가게 수"가 아래 4칸의 가로축, B의 "손님·매출"이 세로축이 됩니다.
- 이 추천과 난이도는 자료 상태를 보고 정리한 의견입니다.

## 3. 판단 틀: 가게 수만 보면 안 되는 이유

```
              손님(수요) 많음
                    │
   ② 기회             │   ① 치열하지만 장사 됨
   가게 적음 · 손님 많음   │   가게 많음 · 손님 많음
   → 들어가 볼 만함       │   → 차별화가 필요
 ───────────────────┼─────────────────── 가게 수 많음 →
   ③ 이유 있는 빈자리     │   ④ 과포화
   가게 적음 · 손님 적음   │   가게 많음 · 손님 적음
   → 피하거나 전문 업종    │   → 피하기
                    │
              손님(수요) 적음
```

| 칸 | 사장님께 하는 말 | 덧붙임 |
|---|---|---|
| ① 치열하지만 장사 됨 | "가게가 많은 건 손님이 많아서일 수 있어요. 들어가려면 남들과 다른 점이 있어야 해요." | "많은 업종은 경쟁이 높아서 피할 것"은 ①과 ④를 합친 말. 대시보드가 둘을 나눠 주면, 피할 곳은 ④뿐이라는 걸 알 수 있음 |
| ② 기회 | "손님은 많은데 이 업종 가게는 적어요. 먼저 들어가 볼 만한 자리예요." | 가설: 임대료가 너무 비싼 경우처럼 다른 이유가 있을 수 있어 현장 확인 필요 |
| ③ 이유 있는 빈자리 | "가게가 적은 건 손님이 적어서일 수 있어요. 경쟁이 없다고 좋은 자리는 아니에요." | 예외: 수선·세탁처럼 기술이 필요한 전문 업종은 원래 가게 수가 적어 따로 표시 |
| ④ 과포화 | "가게는 많은데 손님은 그만큼 없어요. 새로 들어가면 나눠 먹을 몫이 작아요." | 폐업률이 같이 높다면 더 확실한 경고 신호 |

**사장님께 한 문장으로:** 가게 수만 보지 말고, **가게 1곳당 손님이 얼마나 되는지**를 보세요.

**한 축을 더하면 좋은 것: 폐업률.** MTN 보도에 따르면 전국 폐업률은 8.64%이고, 소상공인 6대 업종(제조업·음식업·숙박업 등)은 약 11%입니다. — https://news.mtn.co.kr/news-detail/2026063016075460848 (MTN, 2026-06-30)

## 5. 회의에서 정할 것 3가지

1. **누구를 위한 대시보드인가요?** A · B · C 중 하나, 또는 새 후보
2. **서면을 어디까지로 볼까요?** 전포1동·부전1동·부전2동으로 할지, 다른 동을 더할지
3. **손님·매출 자료는 누가 찾을까요?** 4칸의 세로축이 생겨야 "들어갈지 말지"를 말할 수 있습니다

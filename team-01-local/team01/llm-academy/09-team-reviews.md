# 1단계 · 우리 팀 장소 리뷰 모으기 (4일차 오후 · 팀)

리포트 담당 1번이 내 PC에서 합니다. 2번은 옆에서 건수와 빈칸을 같이 봅니다.

## 먼저 손으로 (브라우저)

1. Chrome에서 `map.kakao.com`을 열고 우리 팀 장소를 검색해, 장소 이름을 눌러 **상세 페이지**(주소가 `place.map.kakao.com/숫자`)를 엽니다.
2. **후기** 탭 → 정렬을 **최신순**으로 바꿉니다.
3. **후기 더보기**를 누를 때마다 3초 쉬며, 후기가 50건쯤 보일 때까지 누릅니다(30건이 안 되는 장소면 있는 만큼).
4. 페이지 빈 곳을 한 번 누르고 `Ctrl`+`A` → `Ctrl`+`C`(페이지 전체 복사).
5. VS Code 왼쪽에서 **내 이름 폴더**에 `inputs` 폴더를 만들고, 그 안에 새 파일 `kakao-raw.txt` → `Ctrl`+`V` → `Ctrl`+`S`.
6. 주소창의 장소 주소(`https://place.map.kakao.com/숫자`)를 복사해 둡니다.

## 그다음 Claude Code에 (장소 이름과 주소 두 곳만 바꿉니다)

```text
내 이름 폴더의 inputs/kakao-raw.txt 는 카카오맵 '○○○(우리 팀 장소 이름)' 후기 탭을 통째로 복사한 글이야. 주소: https://place.map.kakao.com/○○○
이 파일은 고치지 말고 읽기만 해.
1. 후기만 골라 inputs/team_reviews.csv 로 저장해 줘. 첫 줄은 연번,별점,리뷰,등록일 / UTF-8 BOM(엑셀에서 안 깨지게)
2. 리뷰 글은 한 글자도 고치지 말고 그대로. 닉네임·프로필·후기 수·팔로워 같은 글쓴이 정보는 넣지 마.
3. 별점이나 등록일이 복사한 글에 없으면 빈칸으로 두고 지어내지 마. 글 없이 별점만 있는 후기는 빼.
4. inputs/team_reviews_source.md 에 장소 이름, 주소, 모은 날짜(오늘), 건수, 기간(가장 오래된 등록일~가장 최근 등록일), 뺀 것과 그 수를 적어 줘.
5. 다 하면 | 건수 | 기간 | 빈칸이 있는 열 | 뺀 것 | 표로 보여 줘.
```

이렇게 되면 성공: 내 이름 폴더의 `inputs/`에 `team_reviews.csv`와 `team_reviews_source.md`가 생기고, Claude가 건수·기간·빈칸 표를 보여 줍니다. `inputs/`는 팀 규칙(.gitignore)으로 GitHub에 올라가지 않습니다.

확인(2번 담당): CSV에서 아무 리뷰 하나를 골라 `kakao-raw.txt`에서 `Ctrl`+`F`로 찾습니다. 글자 그대로 있으면 됩니다.

막히면:
- 후기가 20건이 안 되면 → 같은 주제의 가까운 장소 하나를 더 모아 `kakao-raw-2.txt`로 두고 "두 파일을 합쳐 줘, 장소 열을 하나 더 만들어"라고 시킵니다.
- 별점 열이 모두 빈칸이면 → 그대로 둡니다. 리포트는 글로 하고, 별점으로 말할 수 없다는 것을 리포트 맨 아래에 적습니다.
- 페이지 전체 복사에 후기가 없으면 → 후기 탭이 열린 채로 다시 `Ctrl`+`A`. 그래도 없으면 첫 후기부터 마지막 후기까지 마우스로 끌어 복사합니다.
- 강의장은 인터넷 주소 하나를 같이 씁니다. '더보기'는 3초씩 쉬며 천천히 누릅니다.

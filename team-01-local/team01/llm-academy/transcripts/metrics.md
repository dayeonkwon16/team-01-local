## 계산 과정 (Python 3.12, 2026-11-17 실행)

```python
import csv, re

rows = list(csv.DictReader(open("inputs/서면젊음의거리_후기_2026-11-17.csv", encoding="utf-8-sig")))
md = open("transcripts/서면_리뷰-영상_태그비교_2026-11-17.md", encoding="utf-8").read()
sec = md.split("## 3. 구글 리뷰 76건 태그")[1].split("## 4.")[0]
tags = {}
for line in sec.splitlines():
    m = re.match(r"^\| (\d+) \| ([^|]+) \|", line)
    if m:
        tags[int(m.group(1))] = [t.strip() for t in m.group(2).split(",")]

# 지표 1
hangul = re.compile(r"[가-힣]")
letters = re.compile(r"[^\W\d_]")
foreign = [int(r["연번"]) for r in rows if not hangul.search(r["리뷰"]) and letters.search(r["리뷰"])]
# 지표 2
t_ids = [k for k, v in tags.items() if "시간대" in v]
tagged = [k for k, v in tags.items() if v != ["태그 없음"]]
# 지표 3
s_ids = [k for k, v in tags.items() if {"쇼핑", "먹거리", "술·유흥"} & set(v)]

print(len(foreign), len(rows))   # 53 76
print(len(t_ids), len(tagged))   # 22 71
print(len(s_ids))                # 41
```

실행 결과: 리뷰 행 76, 태그 행 76 / 지표1 53÷76=0.6974 / 지표2 22÷76=0.2895, 22÷71=0.3099, 22÷153=0.1438 / 지표3 41÷76=0.5395

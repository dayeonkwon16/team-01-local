1. 출처 1·2는 **오픈API**(프로그램으로 불러오는 방식)입니다. 두 페이지 모두 등록일이 2026-09-10입니다.

4. 카드 API 출력 항목: `stdYm`, `hcode`, `hname`, `ryLNm`(업종대분류명), `avgAmt`(월별 일평균 이용금액), `avgCnt`(월별 일평균 이용건수). (출처 2)
5. 생활인구 API 출력 항목: `stdYm`, `hcode`, `hname`, `ages`(연령별), `hpopAvg`(주거), `wpopAvg`(직장), `vpopAvg`(방문) 월별 일평균. (출처 1)
6. 페이지에 보인 "활용신청 수": 생활인구 56, 카드 75 (2026-11-17 기준, 출처 1·2).

## 우리 기획에서의 쓰임
- 공간은 **행정동 단위**이고 `hcode`·`hname` 필드가 있어, 부전1·2동, 전포1·2동만 골라 다른 데이터와 붙일 수 있습니다(출처 1·2).
- 시간은 **월별 일평균**(기준년월 `stdYm`)입니다. 갱신 주기는 API 페이지는 "실시간", 파일 버전은 "연간"으로 서로 다르게 적혀 있습니다(출처 1·2 vs 3).
- 이용 조건: 활용신청 필요(개발·운영 모두 자동승인), 개발계정 트래픽 1,000, 무료, "이용허락범위 제한 없음"(출처 1·2).

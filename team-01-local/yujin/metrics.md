- 같은 분자(영업시간)라도 분모에 따라 0.1000 ~ 0.2857로 달라집니다. 발표할 때는 **분모를 반드시 함께 적습니다**(예: "전포 리뷰 100건 중 12건").
- E의 분모(별점 1~2점 14건): 전포 1, 3, 4, 25, 29, 32, 38, 39, 46, 64, 67, 74, 78, 88번.
- C와 D는 각각 60건, 40건으로 크기가 달라 단순 비교에 주의합니다. 가설: 최근 리뷰일수록 닫힌 가게 이야기가 많다(C 0.1333 > D 0.1000)는 연구 노트(`research/2026-11-18-jeonpo-seomyeon-reviews.md`)의 가설과 같은 방향이지만, 건수 차이가 4건뿐입니다.

## 계산 과정 (python)

```python
import csv
rows = list(csv.DictReader(open('report/2026-11-18-review-tags.csv', encoding='utf-8-sig')))
def has(r, t): return t in r['태그'].split(';')        # 태그 칸은 ';'로 구분
def recent(r): return '년' not in r['등록일']          # "1년 전" 등이 아니면 최근 1년 안

for place in ['전포', '서면']:
    R = [r for r in rows if r['장소'] == place]          # 전포 100, 서면 76
    for tag in ['사람·붐빔', '영업시간', '청결·안전']:
        hit = [r for r in R if has(r, tag)]
        print(place, tag, len(hit), '/', len(R), '=', round(len(hit)/len(R), 4),
              [int(r['연번']) for r in hit])

J = [r for r in rows if r['장소'] == '전포']
h = [r for r in J if has(r, '영업시간')]                         # A 12/100
tagged = [r for r in J if r['태그']]                               # B 분모 87
rec = [r for r in J if recent(r)]; old = [r for r in J if not recent(r)]   # C 60, D 40
low = [r for r in J if int(r['별점']) <= 2]                         # E 분모 14
```

# 조립형 프롬프트 ① 부산 지역 키워드 맵 (두 트랙 공통)

> 세 칸만 내 말로 채워 저장한 뒤, Claude Code에 '이 파일을 열어 할 일을 실행해 줘' 한 줄을 보냅니다(공통 실습서 2단계). 붙여 넣기가 편하면 '완성 프롬프트' 블록을 통째로 붙여도 됩니다.
> 칸을 비워 두면 Claude는 아무 기준 없이 '부산 유명한 것' 목록을 줍니다. 그게 `examples/`의 Before입니다.

## 칸 채우는 법

| 칸 | 이렇게 쓰면 약해요 | 이렇게 쓰면 좋아요 |
|---|---|---|
| [1. 나의 기획 목적] | 부산 키워드 조사 | 6주 뒤 영도를 배경으로 한 로컬 브랜드 페르소나를 만들 재료 찾기 |
| [2. 최우선 판단 기준(우선순위)] | 유명한 것 | ① 출처 URL이 있는 것 ② 내 트랙 산출물로 이어지는 것 ③ 최근 1년 안의 것 |
| [3. 타깃 대상 및 제외할 노이즈] | 없음 | 타깃은 20~30대 부산 밖 방문객. 2025년에 끝난 행사, 같은 축제의 중복 행, 출처 없는 블로그 글은 뺀다 |

## 완성 프롬프트 (세 칸을 채운 뒤 통째로 붙여 넣기)

```text
[1. 나의 기획 목적]
우리 팀이 6주 동안 부산 리테일 상권 2곳(서면, 전포)을 공공데이터로 비교해, 창업자와 소상공인이 "어디에 어떤 업종으로 들어가고, 기존 가게는 어떻게 대응할지" 판단할 근거를 엑셀 대시보드 1개와 기획안 1세트로 모은다

[2. 최우선 판단 기준(우선순위)]
① 공공데이터 원본(데이터셋명, 행정동, 기준월)으로 근거를 댈 수 있다 ② 2025~2026년 데이터에서 확인되는 변화다(공실률, 개·폐업, 카드매출, 생활인구 추이) ③ 서비스의 세 기능(입지·업종 추천, 위험도 진단, 폐점 후속 업종 추천) 중 하나로 이어진다

[3. 타깃 대상 및 제외할 노이즈]
타깃: 서면과 전포 앞에서 창업을 준비하는 20~40대 예비 창업자와, 매출이 줄어 대응책이 필요한 기존 소상공인. 뺄 것: 가상·추정 데이터와 직접 설문, 대상 행정동(부전·전포동) 밖의 점포, 별점만 있거나 상권과 무관한 리뷰, 2024년 이전 리뷰

할 일:
1. inputs/ 폴더의 CSV를 먼저 읽어. busan_festivals.csv, busan_markets.csv, busan_commercial_summary.csv, datalab_diagnosis.csv의 행 수와 컬럼 이름을 표로 보여 줘.
2. 위 [2]의 순서대로 부산 키워드 12개 이상을 골라 keyword-map.md의 키워드 표를 채워. 묶음은 3개 이상.
3. 키워드마다 근거를 '어느 inputs 파일의 몇 번째 행' 또는 '직접 연 웹 페이지 URL'로 적어. 근거가 없으면 상태 칸에 '확인 필요'라고 써. 근거는 표의 '근거' 칸에 적어.
4. [3]의 제외 조건에 걸린 행은 넣지 말고, keyword-map.md의 '뺀 것' 표에 이유와 함께 따로 적어.
5. 회사나 기관이 밝히지 않은 이유는 '가설:'로 시작해.
6. 다 쓰면 examples/before-after-data-note.md 또는 examples/before-after-creative-note.md의 After와 비교해서 모자란 점 3가지를 말해 줘.
```

## 붙여 넣은 뒤 확인

- [ ] 키워드마다 근거(파일 행 또는 URL)가 있다
- [ ] '뺀 것' 목록이 있고, 내가 [3]에 쓴 조건과 맞다
- [ ] 숫자는 inputs 파일의 숫자와 똑같다(Claude가 반올림하거나 바꾸지 않았다)

# 03 · 영상 자막 받기와 요약 노트 (5일차 2교시)

busan_02 창의 Claude Code에서 보냅니다. 노란 칸만 우리 줄에 맞게 바꿉니다. **한 사람이 영상 두 편까지**만 받습니다.

```text
나는 [내 이름 폴더 이름]이고, fieldwork-plan.md의 [줄 번호]번 줄([그 줄에서 영상으로 확인할 것])을 맡았어.
유튜브 영상 [영상 주소] 의 [영어/한국어] 자막을 받아 [내 이름 폴더 이름]/raw/video/[저장 이름].txt 로 저장하고, 요약 노트를 [내 이름 폴더 이름]/raw/video/[저장 이름]-note.md 로 써 줘.
1. 프로그램 설치가 필요하면 관리자 권한 없이 설치해 (pip install --user youtube-transcript-api).
2. 자막 파일 맨 위에 출처 한 줄: 유튜브 · 영상 제목 · 채널 · 올린 날 · 링크 · 자막 종류(사람이 단 자막/자동 생성) · 모은 날. 자막 줄마다 [분:초]를 붙여.
3. 노트는 표: | 분:초 | 장면 | 원문 한 줄 | 우리말 뜻 | 계획서 '확인할 것' 어느 칸 |
4. 계획서 [줄 번호]번 줄 '오늘 결과에서 확인할 것' 칸에 답하는 장면만 넣어. 원문 한 줄은 자막 파일에서 글자 그대로 옮겨.
5. 자막만으로 알 수 없는 것(화면을 봐야 아는 것)은 [자막에 없음]으로 적어. 지어내지 마.
6. 영상은 이 한 편만 받아.
```

## 강사가 먼저 보낸 것 (동래온천 수달 팀 · 계획서 3번 줄 ②)

```text
나는 inae이고, fieldwork-plan.md의 3번 줄 ②(외국인이 동래를 걸어 다닌 영상의 계단·오르막·엘리베이터 장면)를 맡았어.
유튜브 영상 https://www.youtube.com/watch?v=gGSk1Ud0yA4 의 영어 자막을 받아 inae/raw/video/금강공원-케이블카.txt 로 저장하고, 요약 노트를 inae/raw/video/금강공원-케이블카-note.md 로 써 줘.
(1~6번 줄은 위와 같음)
```

## 막히면

설치가 막히거나 받기 실패가 이어지면 멈춥니다. YouTube 영상 아래 **…더보기 → 스크립트 표시**에서 필요한 부분을 복사해 `raw/video/[저장 이름].txt`에 붙여 넣고, 맨 위 출처 한 줄은 손으로 씁니다. 그다음 위 프롬프트에서 "자막을 받아" 대신 "이 txt를 읽고"라고 바꿔 노트만 만듭니다.
